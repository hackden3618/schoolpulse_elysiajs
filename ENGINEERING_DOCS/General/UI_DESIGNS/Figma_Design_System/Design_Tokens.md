| Token | Hex | Usage |
|-------|-----|-------|
| `color-brand-primary` | #1E40AF | Primary buttons, links, active nav |
| `color-brand-secondary` | #F59E0B | Accent / highlights |

| `color-warning` | #F97316 | Late, pending, due |
| `color-danger` | #EF4444 | Absent, overdue, error |
| `color-info` | #3B82F6 | Info banners |
| `color-bg-page` | #F9FAFB | Page backgrounds |
| `color-bg-card` | #FFFFFF | Card surfaces |
| `color-bg-sidebar` | #1F2937 | Sidebar navigation |
| `color-text-primary` | #111827 | Headings, body |
| `color-text-secondary` | #6B7280 | Labels, captions |
| `color-text-inverse` | #FFFFFF | On dark/sidebar backgrounds |
| `color-border` | #E5E7EB | Borders, dividers |

## Component Library (Figma)

The following shared component variants should exist in the Figma Design System file:

- Button (Primary, Secondary, Ghost, Danger, Icon-only, Loading)
- Input (Text, Phone, Email, Password, Number, Date, Select, Search)
- Textarea
- Checkbox, Radio, Toggle
- Badge / Pill (Active, Inactive, Pending, Success, Warning, Danger, Info)
- Table (Header row, Data row, Empty state, Loading skeleton)
- Card
- Modal / Dialog (Default, Alert, Confirm)
- Drawer / Slide-over
- Dropdown Menu
- Pagination
- Empty State (Illustration + Message + CTA)
- Error State
- Loading Spinner
- Sidebar Nav Item (Active, Inactive, Collapsed, With Badge)
- Top Nav Bar
- Search Bar
- Filter Bar
- Breadcrumbs
- Tabs
- Accordion
- Toast / Notification
- Stepper (multi-step forms)
- Tooltip
- Avatar (User, School logo)
- Action Menu (3-dot menu)
- Data Card (Student card, Invoice card)
- Progress Bar
- Chart / Mini-chart (line, bar, donut)
